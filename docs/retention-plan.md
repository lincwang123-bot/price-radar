# AIradar 回访功能

已确认的产品方向：游客关注具体商品，确认邮箱后同步并接收自选条件通知；增强热门产品参考页；提供续费日期、每周行情和分享卡片；观察真实回访。

沿用 Node SSR、现有报价分类与独立投稿 SQLite。新增表使用 `retention_` 前缀，受现有私有数据库备份保护。关注不影响报价排序。新增功能不改采集原始记录。

交付顺序：
1. 同规格行情投影、观察历史、邮箱验证码与会话、关注和通知状态机。
2. 游客清单、邮箱同步、条件提醒、产品页参考信息、续费与日历导出。
3. 行情周报、图片分享、后台回访指标、隐私说明。
4. 自动测试、桌面及手机实际交互验证、部署前备份、上线核验和临时进程清理。

验收重点：年/月、交付方式、地区、币种与单位不混算；抓取失败不能当售罄或恢复库存；未知规格不触发目标价通知；首次关注不误报降价；邮件仅发往确认后的邮箱（验证码除外），支持暂停和退订；验证码限流、会话隔离、跨站请求防护；历史不足不补造；无 JavaScript 时公开参考内容仍可访问。

新增行情统计从首次实际观察开始，既有来源历史继续保留。邮件发送接受状态不等于用户已读或最终到达收件箱。测试使用模拟邮件，不向现有商家发送测试消息。
