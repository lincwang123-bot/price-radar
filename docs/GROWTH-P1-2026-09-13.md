# 增长 P1：购买条件、行情依据与分享

本轮优先让热门产品的购买条件更准确，并让价格观察能被分享、追溯。

- 16688 与 ShopApi 的单商品公开说明补充 `descriptionScope`；多规格父说明继续隔离。没有足够依据的报价保留价格并标记待确认。
- 修复将“手续费”误判成续费、将“质保订阅30天”当成订阅时长、将明确列举的封号原因当成交付方式的问题。新开否定句不再误当新开资格。
- 分开识别到期后续费、提前续费、覆盖原有时间、可累计时间；冲突保持待确认，明确限制进入规格身份和购买说明。
- 私有提醒库只新增 `retention_market_evidence`：保存每天最后一次有效起价所对应的去标识报价集合。时间戳必须与原日观察匹配；不回填旧证据。
- 周报区分同店同商品标价变化、新观察到低价来源、可用来源变化、两者并存。缺少两端证据显示原因待确认，不推断商家调价动机或上架时间。
- 分享弹窗提供复制链接、PNG 下载、X 与 Telegram 编辑入口；周报链接包含日期及规格组，组筛选在20条上限之前完成。产品链接包含准确购买规格。不会自动在社交平台发布。
- 单规格周报使用 `noindex, follow`，canonical 保留整期周报；不扩增薄内容索引页。

验证：617 项自动测试通过；390px 手机与1440px桌面完成首页价格、具体规格、复制、图片下载、X/TG目标和周报具体条目交互，无控制台错误或横向溢出。周报跨日归因测试使用独立内存库的测试数据，不进入生产历史。

原店验证：2026-09-13 的公开 16688 商品 `G26143891` 为 Claude Pro 月卡，说明明确支持续费并要求会员到期后续费，标注质保30天；新解析能够区分1个月订阅和30天质保。以最新采集为准。
