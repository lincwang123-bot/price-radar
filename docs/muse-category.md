- `muse-account`：标题明确交付 Muse 成品号或账号。保留标注的 token 数量，不据此推断订阅档位；期限、交付或额度单位不明时不作为同规格起价。

Muse Code、Spark/API、余额/点数充值、邀请码/代刷、接码、仅资格服务、视频托管同名业务及混合品牌/档位不归为上述商品。

现有已批准店铺在正常采集周期内重新分类原始目录和缓存，不删除历史或强制刷新。LDXP 的默认有限关键词名单加入 `muse`，保持原有请求预算、周期和访问防护；显式自定义关键词仍以配置为准。

新申请仍需有效邮箱、公开目录同意和当前版本的有效商品检测，沿用现有审核与邮件额度规则，不把批准标为身份核验。已失败的待审测试不会因新增品类自动变为成功；如需重测，须逐条核对访问范围、频率与失败原因。
