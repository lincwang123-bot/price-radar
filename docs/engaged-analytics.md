# 有效浏览并行统计

`AIRADAR_ANALYTICS_ENGAGED` 大小写不敏感：

- `report`（未设置或非法值的默认值）：保留官方 PV/UV，另展示有效浏览。
- `filter`：展示优先使用有效浏览，官方原始数字仍可见；官方写入完全不变。
- `off`：停止有效浏览写入，恢复旧公开/后台展示和 CSV 列。仅需调整开关并重启进程；保留数据库和新增表，不执行 VACUUM、删表或迁移回滚。

公开页停留默认 4000ms 或发生 window scroll 时先到先发一次 POST。可通过 `AIRADAR_ANALYTICS_ENGAGED_DELAY_MS` 设置非负毫秒阈值。源站和缓存页面均使用同一脚本；官方缓存补记仍只走 public-hit。旧缓存中的脚本在 off 时由接口忽略。

有效浏览复用官方公开页面范围、浏览器分类及 HMAC 访客摘要。成功的增长互动和商家 visible/click/contact_click 同步尝试记数；页面来源仅在内存判定。每访客 30 秒内的有效信号合并，可能少计快速重复访问或同网络浏览器的多标签访问。去重窗口仅保存在进程内，进程重启会重置。有效信号有独立的每分钟全局 600 / 每访客 60 上限，不占用官方限额。

日汇总长期保留，访客摘要按官方相同的 30 天截止日期清理。新表只存日期、计数与摘要，不存原始请求信息。有效 UV 仍是估算，不等于真人数量、广告曝光或成交。

观察官方数字是否延续原口径、有效/原始比例、统计健康状态、心跳接口拒绝与限流情况、快照更新时间及 CSV 列。公开快照每五分钟更新；有效字段不满足非负整数和上界校验时仅隐藏有效字段，保留官方数字。已启用 Cloudflare 来源的流量条继续展示其独立口径，不混入本地 PV/UV。
