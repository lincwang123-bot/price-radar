# BBShare 公开页面接入

- 注册精确来源 `https://www.bbshare.site`，仅作为申请测试/批准后采集的适配器，不加入默认公开采集列表，不代替人工审核。
- 根域会跳转；已确认的原申请人回复允许站方通过 `correctPendingMerchantUrl` 更正待审核申请的 www 地址。操作需要旧网址、版本、原邮箱匹配和依据，写入审计并递增版本，使旧测试失效；不变更归属确认、邮箱、通知预算，不自动批准。
- 先读取并核对 `robots.txt`。当前规则允许公开页面，禁止 `/api/` 和 `/admin`，因此只读取主页公开 ItemList 及其列出的商品详情，不探测 API、登录、订单或客户资料，也不执行页面脚本。
- 最多读取 18 个明确列出的详情页，总请求上限 20（含规则和主页），仍受 30 秒总超时及每响应 512 KiB 限制；串行请求，开始时间至少间隔 1 秒。缺页、变更、数量超限或信息不一致时整批失败，不发布不完整目录。
- 详情页 SKU、同源规范 URL、结构化标价与可见标价交叉核对。周期读取“订阅周期”而非质保天数；库存仅记录公开 availability 声明，不代表真实履约。明确成品号标题优先，不使用该站自动追加的“代充”描述将其归为代充。
- 单纯读取公开页面不保证站方声明实时或准确；商品仍经过统一展示、过期、交付分类、库存与质保过滤，购买以原店为准。
