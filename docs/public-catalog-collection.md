# 通用公开目录回退

未知独立店铺在既有 Dujiao/Kami 接口未识别时，尝试公开目录；已登记的接口采集器遇到 404、目录格式变化或 5xx 时复用该能力。审核试采、已批准商家周期采集、固定直采来源使用相同流程。有效 API 结果保持原有报价 ID，不额外抓取详情。

支持的证据路径：

- 公开商品卡片、JSON-LD ItemList、明确的目录/分页链接、robots 声明的同源 sitemap。
- 详情页 Product JSON-LD 或 microdata，与可见标题和人民币标价交叉核对；无结构化数据时要求列表和详情标价一致。
- 脚本加载的商城：只读取主页明确引用的最多两个静态模块，识别已验证的 `/api/store/products` 契约、人民币分转元格式函数及详情路由，再读取实时列表和详情 JSON。模块不会执行；不使用内置演示目录、销量、上游库存快照或第三方商品地址。

记录商品标题、类别、价格、订阅/交付证据、库存、商品说明、售后原文和采集方法。缺失字段保持未知，月卡不推导为全月质保，营销词“顶尖体验”不表示试用。

公开页面读取使用同源 HTTPS、公共 DNS 固定解析、GET、无认证/重定向；遵守 robots 的有效规则和限速。robots 逐行解析参考 [RFC 9309 §2.3.1.5](https://www.rfc-editor.org/rfc/rfc9309.html#section-2.3.1.5)。访问拒绝、验证码、网络错误立即停止，不通过其他路径重试。

每次试采总预算 30 秒/20 请求，HTML 阶段最多 18 请求（预留两个既有 API），最多 3 个目录页、14 个 HTML 商品或 12 个脚本商城商品；响应上限 1 MiB。任一列出的商品缺失、价格冲突、分页不完整或预算不足，整轮失败而非发布截断目录。

共享域名的平台继续使用明确的店铺适配器，不拿平台首页冒充某家店铺目录。既有专用 HTML 适配器保留其更严格的验证。此改动不新增默认店铺、不自动批准申请，不抓取订单、支付、账号或联系商家。
# 兼容平铺公开商品目录

独立店铺自动探测 `/api/v1/public/products` 时，除独角数卡 SKU 格式外，也支持包含 `items`（或 `data.items`、`data.list`、`products`）的平铺商品目录。只取一个数组，兼容别名不重复计数。必须提供 `page`、`page_size`、`total`；商品需包含稳定 ID、名称、元单位价格、币种和同源 HTTPS 单品链接。库存别名与元/分价格同时存在时必须一致。声明多规格但没有独立报价的商品不能按父商品起售价收录。

每页请求 100 条、最多 5 页/500 个商品、每次响应最多 1 MiB。校验返回页码、总数、每页数量及跨页重复；目录不完整时不发布部分报价。维持动态商家授权、DNS 地址校验、请求预算与访问拒绝处理。此格式用于预检和正常采集，不针对单独域名放宽规则。
