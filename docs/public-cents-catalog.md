# 浏览器加载的公开商品目录

HTML 目录没有商品时，可识别页面明确引用的 `storefront-*.js` 或 `product-detail-*.js` 模块。只读解析模块文本，不执行 JavaScript。

必须同时确认模块读取 `/api/products`、使用返回的 products/categories、商品链接为 `/products/<id>`，以及显示人民币价格时调用的导入函数确实除以 100。格式化模块也必须出现在页面同源的公开模块链接中。未确认这些信息，不猜测该接口或价格单位。

实时接口返回 categories/products；商品需要明确的 active、人民币分整数 price、单规格 sku、stockState、stockQuantity、canPurchase。重复标识、分页未完整返回、价格单位不明或库存冲突会阻止本轮发布。售罄与暂不可购商品继续经过原有报价过滤。模块中的静态示例商品不作为价格或库存来源。

沿用原有 DNS 固定、同源 HTTPS、robots、超时、请求数与响应体限制。一次完整读取只需 robots、首页、展示模块、价格格式化模块和实时目录；未知店铺原有接口识别仍共用总读取预算。不访问认证、订单、支付或商品图片接口。

首个核对店铺为 aliAI（alivip.vip）。此识别逻辑不绑定店铺域名或构建哈希，同格式商店可以复用；页面结构变化后必须重新核对，不以过期静态默认价格补齐。
