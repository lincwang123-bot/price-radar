# 公开 HTML 目录容量和现价识别

2026-09-09 检查星宝小店申请时，首页明确列出 15 件商品，原先 14 件上限在读取详情前拒绝了整个目录。公开 HTML 适配器现允许最多 16 件：两次标准 API 探测、robots.txt、首页和 16 个详情页合计仍不超过现有 20 次请求上限。额外目录页继续计入相同预算；超限、缺页或不一致仍不发布部分结果。

详情页的 `glass-price-strike` 原价和现价处于同一个价格容器。现价提取会先移除有明确划线/旧价语义的整个子树，包括 `s`、`del`、旧价类名和内联 `line-through`，再读取父级价格文本，避免父容器把原价重新计入。仍要求商品名称、列表现价、详情可见现价以及结构化价格一致；两个未标明旧价的不同金额仍拒绝采集。

此次完整只读试采读取 15 件商品，13 条通过既有报价过滤。实现不包含特定店铺域名或硬编码价格。回归覆盖 15/16 件目录、17 件拒绝、总请求预算、嵌套原价排除和真实现价冲突。

## 未知店铺先检查 robots

未知独立站的目录识别先读取 `/robots.txt`，使用 `AiradarBot/1.0`。只有明确允许访问的候选标准接口才会被探测；禁止接口不会阻止继续读取允许的公开商品页面。robots 返回 404 视为没有规则，访问拒绝、验证码或读取失败则停止本轮。

解析出的规则同时约束接口分页、详情请求和失败重试，并遵守 Crawl-delay。HTML 回退复用同一份规则，不重复请求 robots。原有同源 HTTPS、公开网络、20 次请求、30 秒和响应大小限制保留；不抓取下单页或商品图片。

此顺序修正作用于未知商家目录发现流程，已登记的平台专用采集器沿用原有流程。
